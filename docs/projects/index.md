# Projects Overview {: .nanda-main-title }

This page is a map of what is available and where each project sits; details remain on the project sites. For the underlying idea and phased roadmap, see the [Research Overview](../research/index.md).

## Applied Projects

These projects apply the NANDA stack to public-interest and civic settings. They are deployments and project directions built on the infrastructure above, not additional infrastructure layers.

<div class="nanda-project-list">

  <a href="https://civicagents.projectnanda.org/" target="_blank" rel="noopener noreferrer" class="nanda-project-row">
    <div class="nanda-project-name">Civic Agents <span class="nanda-project-arrow">↗</span></div>
    <div class="nanda-project-desc">City and government applications built on the Project NANDA protocol, with active hubs across India, Massachusetts, Milan, and Charlotte.</div>
  </a>

  <a href="https://tiny.cc/agents4ma" target="_blank" rel="noopener noreferrer" class="nanda-project-row">
    <div class="nanda-project-name">Agents4MA <span class="nanda-project-arrow">↗</span></div>
    <div class="nanda-project-desc">Statewide civic infrastructure framework for private agents: An AI Agent for Every Massachusetts Resident.</div>
  </a>

  <a href="http://kumbhdoot.org" target="_blank" rel="noopener noreferrer" class="nanda-project-row">
    <div class="nanda-project-name">KumbhDoot <span class="nanda-project-arrow">↗</span></div>
    <div class="nanda-project-desc">Voice-first, multilingual personal-agent framework for the Nashik Kumbh Mela 2027, connecting pilgrims with civic and business services through digital public infrastructure.</div>
  </a>

  <a href="http://digidoot.in" target="_blank" rel="noopener noreferrer" class="nanda-project-row">
    <div class="nanda-project-name">DigiDoot <span class="nanda-project-arrow">↗</span></div>
    <div class="nanda-project-desc">Personal citizen-agent framework designed to help citizens discover and use government and private services through natural language, voice, and local context.</div>
  </a>

</div>
